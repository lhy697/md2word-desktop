# 支持范围与限制

- 目标平台 Windows 11 x64 / Python 3.12，未承诺其他系统或架构。
- 输入为 UTF-8 Markdown、TXT 或粘贴文本，最大 2 MiB；AST 节点上限 100,000，嵌套深度上限 96。超限提示而非截断。
- 支持六级标题、常见列表、简单管道表格、引用、代码、链接和检测后支持的数学公式。
- 不嵌入本地或远程图片，图片描述和引用信息以可见内容保留；不支持任意复杂 HTML、合并表格或全部 LaTeX 命令。
- 公式可能降级为可见源码并提示；完整性不确定时阻断导出。预览可显示不代表 Word 可编辑公式转换成功。
- 预览用于结构和样式查看，不模拟精确分页；字体依赖本机合法安装的字体。
- 达到 100,000 字符时使用手动预览策略。预览和导出分别限制工作线程和等待任务，缓存有界。
- 自动草稿只能恢复最近一次成功快照；未落盘、保存失败或关闭自动保存后的修改可能无法恢复。
- 同名目标在无法可靠替换时要求另存；源 Markdown 不被写回覆盖。
- 没有 AI 内容生成、PDF 导出、批量转换、自动目录或云同步。
- 独立干净电脑、物理断网、完整 Word/WPS 页面及打印和长时间真实使用仍需单独验收；WPS 尚未单独验收。
