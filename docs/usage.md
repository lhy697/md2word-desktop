# 使用方法

1. 启动 GUI，粘贴已有 AI 输出或导入 UTF-8 Markdown/TXT。
2. 选择 Markdown 或纯文本模式。若需要保留标题、列表和表格，使用原始 Markdown 文本。
3. 在整篇排版中调整字体、字号、行距、段距和页边距，可保存个人样式。
4. 在预览中选中文字，使用局部排版调整选区或所在段落。
5. 检查问题提示后导出到新 DOCX，打开成品复核公式、字体、宽表和分页。

快捷键：Ctrl+N 新建，Ctrl+O 导入，Ctrl+E 导出，Ctrl+Enter 刷新，F1 帮助。

自动草稿只恢复最近成功保存的快照。重要内容及时导出；关闭自动保存不会删除已有草稿，清空需明确执行。程序不写回原始 Markdown 文件。

程序目录与用户数据独立。删除程序不会自动删除用户草稿和个人样式。
